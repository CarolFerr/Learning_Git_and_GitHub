Aqui esta sendo contido o refinamento do projeto da calculadora.
[]: # Aqui estão os passos que foram seguidos para o refinamento do projeto da calculadora:
[]: # 1. **Criar o repositório**: Criar um repositório no GitHub para o projeto da calculadora.
[]: # 2. **Clonar o repositório**: Clonar o repositório para a máquina local usando o comando
[]: #    `git clone <URL do repositório>`.
[]: # 3. **Criar um branch**: Criar um branch para o refinamento do projeto usando o comando
[]: #    `git checkout -b <nome do branch>`.
[]: # 4. **Adicionar arquivos**: Adicionar os arquivos do projeto da calculadora ao repositório local usando o comando
[]: #    `git add .`.
[]: # 5. **Fazer commit**: Fazer um commit das alterações usando o comando
[]: #    `git commit -m "Refinamento do projeto da calculadora"`.
[]: # 6. **Fazer push**: Fazer um push do branch para o repositório remoto usando o comando
[]: #    `git push origin <nome do branch>`.
[]: # 7. **Criar um pull request**: Criar um pull request no GitHub para solicitar a revisão do branch.
[]: # 8. **Revisar o pull request**: Revisar o pull request e fazer comentários, se necessário.
[]: # 9. **Fazer merge**: Fazer o merge do branch com o branch principal
[]: #    usando o comando `git merge <nome do branch>`.

- Soma
- Subtração
- Multiplicação
- Divisão
- Exponenciação
- Raiz quadrada
- Porcentagem
- Logaritmo
- Fatorial
- Conversão de bases numéricas (decimal, binário, octal e hexadecimal)
